ROC curve generated from two Normal score distributions (positives ∼ N(0.62, 0.16), negatives ∼ N(0.38, 0.16)). Precision at each point is recomputed from TPR, FPR and prevalence via Bayes' rule: Precision = (TPR·prevalence) / (TPR·prevalence + FPR·(1−prevalence)).
